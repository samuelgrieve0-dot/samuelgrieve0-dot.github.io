Folklore Studio privacy policy

Last updated: 7 November 2026

Folklore Studio is a private tool used only by the owner of the Folklore Sports YouTube channel to manage that channel. It is not offered to the public.

What it accesses

  • YouTube (YouTube Data API and YouTube Analytics API): the Folklore Sports channel's own videos, titles, descriptions, thumbnails, captions, comments and analytics, so that videos can be uploaded, scheduled and managed and comments can be answered.
  • Google Drive (drive.file scope): only files that Folklore Studio itself creates, used to store finished videos for posting.

How the data is used

The data is used only to run the Folklore Sports channel. It is not sold, not shared with third parties, not used for advertising, and not used to train AI models. Access tokens are stored only in the owner's private environment settings.

Folklore Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. YouTube's own terms and Google's privacy policy also apply: YouTube Terms of Service, Google Privacy Policy.

Contact

Questions can be sent through the Folklore Sports YouTube channel: youtube.com/@FolkloreSports.
